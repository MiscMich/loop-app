# Provenance

This repository is a sanitized public export of a privately developed project. The public history starts with one root commit so private deployment metadata, account identifiers, abandoned assets, and unrelated operational notes never enter GitHub history.

The application code, tests, native widget target, and demo fixtures in this repository are real source code. The public build defaults to fictional data and does not include hosted backend credentials. Native services require the adopter's own platform configuration.

The private source history is retained separately and is not part of this public repository.
